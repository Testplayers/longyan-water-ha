# 04 · 使用说明

## 添加集成

1. **设置 → 设备与服务 → 添加集成**
2. 搜索「**龙岩水发自来水**」（或 `longyan_water`）
3. 输入网厅的**手机号**和**密码**，提交

此时集成会自动：

- 请求一张验证码图片
- 用内置 OCR 识别
- 识别成功 → 直接登录成功，集成添加完成
- 识别失败（重试 12 次仍失败）→ 跳到**验证码输入界面**，页面里直接显示验证码图片，手动输入即可

4. 登录成功后，集成会自动拉取该账号下的**所有户号**，每个户号生成一个设备 + 8 个实体

### 设备与实体

设备名形如 `自来水 015-251217358`（`015-251217358` 是户号），制造商为「龙岩水发自来水」。

| 实体名 | entity_id 后缀 | 单位 | 说明 |
|---|---|---|---|
| 账户余额 | `_zhang_hu_yu_e` | CNY | 账户当前余额 |
| 欠费金额 | `_qian_fei_jin_e` | CNY | 一般为 0 |
| 本期用水量 | `_ben_qi_yong_shui_liang` | m³ | 最近账单周期用水量，可接能源面板 |
| 本期读数 | `_ben_qi_du_shu` | m³ | 本期抄表读数（账单未出时为 0） |
| 上期读数 | `_shang_qi_du_shu` | m³ | 上期抄表读数 |
| 水价单价 | `_shui_jie_dan_jie` | CNY/m³ | 当前执行水价 |
| 本期应缴 | `_ben_qi_ying_jiao` | CNY | 本期账单金额 |
| 上次抄表日期 | `_shang_ci_chao_biao_ri_qi` | 日期 | 抄表日通常为每月 1 号 |

> 实体 ID 用的是设备名 + 实体的**拼音**，例如：
> `sensor.zi_lai_shui_015_251217358_zhang_hu_yu_e`

「本期用水量」实体还附带属性：账单月份、上期读数、本期读数、应缴金额、已缴金额、缴费状态。

### 看懂这些数字

网厅的账单是**按抄表周期**（每月 1 号抄表）出的，所以会出现下面两种情况，都是正常的：

- **本期读数 = 0**：本期账单还没生成，`currentRead` 为空/0，
  此时用水量看「本期用水量」实体（它取的是最近一期账单的 `consumedVolume`）。
- **余额长时间不变**：水费是按月出账的，没出账的日子余额自然不动。

## 数据刷新

- 默认 **每 6 小时**刷新一次，无需人工操作
- token 过期会自动重新登录（含验证码 OCR）
- 想立刻更新：**设置 → 设备与服务 → 该集成 → 右上角 ⋮ → 重新加载**

### 修改刷新间隔

编辑 `custom_components/longyan_water/const.py`：

```python
UPDATE_INTERVAL_HOURS = 6      # 改成 3 就是每 3 小时一次
```

改完重新部署 + 重启 HA 生效（见 [03 · 安装部署](03-安装部署.md)）。

> 建议不要低于 1 小时：网厅数据本身按月更新，刷太快没意义，还可能被风控。

## 接入能源仪表板

1. **设置 → 仪表板 → 能源 → 添加用水**
2. 选择「本期用水量」实体
3. 保存后即可看到月度用水柱状图

## 自动化示例：余额不足提醒

```yaml
# 水费余额低于 20 元时发通知
automation:
  - alias: 水费余额不足提醒
    triggers:
      - trigger: numeric_state
        entity_id: sensor.zi_lai_shui_015_251217358_zhang_hu_yu_e
        below: 20
    actions:
      - action: persistent_notification.create
        data:
          title: 💧 水费余额不足 20 元
          message: 请及时缴费。
```

## 自动化示例：集成失联告警

```yaml
  - alias: 水表集成失联告警
    triggers:
      - trigger: state
        entity_id: sensor.zi_lai_shui_015_251217358_ben_qi_yong_shui_liang
        to: "unavailable"
        for: "00:30:00"
    actions:
      - action: persistent_notification.create
        data:
          title: ⚠ 自来水集成失联
          message: 数据已 30 分钟不可用，请检查网厅是否改版或账号是否异常。
```

## 修改密码 / 更换账号

目前不支持在界面上改密码，需要：

1. 删除该集成条目
2. 重新「添加集成」，输入新的手机号/密码

> 配置存在 `/config/.storage/core.config_entries` 里（明文密码，注意不要外泄该文件）。
