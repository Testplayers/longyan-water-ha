# 02 · 接口原理

> 本章记录逆向出来的网厅接口细节，是后续排错和适配改版的基础。

## 基本信息

| 项 | 值 |
|---|---|
| 站点 | `https://service.fjlyzls.com` |
| 平台 | 杭州水务 `iwater`（`waterCorpId = 3`） |
| 请求方式 | `POST`，`Content-Type: application/x-www-form-urlencoded` |
| 请求体 | 单参数 `requestPara=<JSON>`（要做 URL 编码：`+`→`%2B`，`&`→`%26`） |
| 前端版本号 | `appVersion = 1.0.2` |
| token 存放 | 前端放 `sessionStorage.waterUserToken` |

## 通用参数

每次请求的 JSON 里都要带上这些固定字段（见 `const.py: _fixed_params`）：

```json
{
  "token": "<登录后拿到的 token，登录接口传 null>",
  "waterCorpId": 3,
  "UNID": "",
  "areaId": 0,
  "accountType": "XJ",
  "apiType": "PC",
  "appVersion": "1.0.2"
}
```

## 接口一：图形验证码

```
GET /iwater/nt/validateCode.json?timestamp=<毫秒时间戳>
```

- 返回图片（JPEG）。响应头里带 Cookie，登录时要带上同一个会话。
- `timestamp` 参数也会在登录时一并提交，用于校验验证码时效。

## 接口二：登录

```
POST /iwater/nt/wt/login.json
requestPara = {
  "userName": "<手机号>",
  "password": "<md5(明文密码)>",
  "code": "<验证码>",
  "timestamp": "<取验证码时的毫秒时间戳>",
  ...通用参数
}
```

响应：

```json
{
  "status": 0,
  "message": "登录成功",
  "data": { "userInfo": { "token": "xxxx", ... } }
}
```

**状态码约定**（`api.py` 中的处理）：

| status | 含义 | 处理 |
|---|---|---|
| 0 | 成功 | 取 `data.userInfo.token` |
| 3 | 验证码错误 | 抛 `CaptchaError`，重试 |
| 5 | 用户名或密码错误 | 抛 `AuthError`，停止重试 |
| 11 | token 已失效（查询接口） | 抛 `AuthError`，coordinator 自动重登 |
| 其他 | 未知错误 | 抛 `LongyanWaterError`，日志记录 `message` |

> ⚠️ 重要：早期测试时验证码**不校验**（随便填也能登录），后来（2026-09 起）开始真实校验了，
> 所以集成里必须做 OCR。如果哪天网厅又放松校验，`login_auto` 反而更容易成功。

## 接口三：查询户号列表（核心数据源）

```
POST /iwater/v1/watermeter/queryUserMeterList/v1.json
requestPara = { ...通用参数（带 token） }
```

响应 `data` 是一个**数组**，每个元素是一个户号（水表），关键字段：

```json
{
  "bsh": "015-251217358",          // 户号，作为唯一 ID
  "balance": 82.76,                 // 账户余额（元）
  "arrearage": 0,                   // 欠费金额
  "unitprice": 2.75,                // 水价单价（元/m³）
  "currentRead": 0,                 // 本期读数
  "lastRead": 10,                   // 上期读数
  "lastreaddate": "2026-09-01",     // 上次抄表日期
  "billAmount": 36.5,               // 账单金额
  "payMentList": [                  // 账单列表（[0] 是最新一期）
    {
      "costDate": "2026-08",        // 账单月份
      "consumedVolume": 10,         // 用水量（m³）
      "currentRead": 0,
      "lastRead": 10,
      "payablePrincipal": 36.5,     // 应缴金额
      "paidAmount": 36.5,           // 已缴金额
      "payStatus": "已缴费"
    }
  ]
}
```

> 注：`currentRead: 0` 表示本期账单还没生成，不是数据错误。
> 用水量以 `payMentList[0].consumedVolume` 为准（当期账单的用水量）。

## 自己重新抓包（网厅改版时用）

1. Chrome 打开 <https://service.fjlyzls.com>，按 `F12` → **Network** 面板
2. 勾选 `Preserve log`，登录并点进「我的水表 / 账单查询」
3. 在筛选框输入 `json`，重点看三个请求：
   - `login.json`（登录，POST）
   - `validateCode.json`（验证码，GET）
   - `queryUserMeterList`（数据，POST）
4. 点开请求 → **Payload** 看 `requestPara` 内容；**Response** 看返回字段
5. 把新字段补进 `sensor.py` / `api.py`

JS 源码里搜索关键字也能快速定位接口路径：

```bash
curl -s https://service.fjlyzls.com/ | grep -oE 'src="[^"]+\.js"'   # 找 JS 文件
```

然后在 JS 里搜 `queryUserMeterList`、`login.json` 等字符串。
