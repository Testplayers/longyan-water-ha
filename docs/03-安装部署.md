# 03 · 安装部署

## 前置条件

- Home Assistant **2024.1.0 或更高**
- 龙岩水发自来水网厅的**账号（手机号）+ 密码**
- 需要的 Python 包：`Pillow`（`manifest.json` 里的 `requirements` 会自动安装，通常 HA 已自带）

## 方式一：手动复制（通用）

1. 把仓库里的 `custom_components/longyan_water` 整个文件夹复制到 HA 配置目录：

```
/config/custom_components/longyan_water/
├── __init__.py
├── api.py
├── captcha_templates.json
├── config_flow.py
├── const.py
├── coordinator.py
├── entity.py
├── manifest.json
├── ocr.py
├── sensor.py
├── strings.json
└── translations/
```

2. **重启 Home Assistant**（自定义集成新装必须重启，不能只重载）
3. 继续看 [04 · 使用说明](04-使用说明.md) 添加集成

> 文件上传途径（按方便程度）：
> - **Samba / SMB 共享**：HA 装有 Samba 插件的话，直接在 Windows 资源管理器里拖进去
> - **File Editor / Studio Code Server 插件**：在 HA 网页里新建文件粘贴内容（适合少量改动）
> - **SSH + SCP**：见方式二

## 方式二：SSH 一键部署（推荐，适合反复更新）

适合 HAOS（Home Assistant OS），**不需要挂载目录、不需要 HA 里装任何插件**。
原理：用 SSH 把打包好的 `tar.gz` 通过 stdin 流式写到远程主机，解压到 `/homeassistant/custom_components/`，再重启。

### 1. 准备 SSH

HA 需要能 SSH 登录，两种途径：

- **官方 SSH 插件**：安装 *Terminal & SSH* 插件，端口默认 `22`
- **主机调试 SSH**：HAOS 开启 Developer SSH（端口 `22222`）

密钥方式（推荐）：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_ha     # 本机生成
# 把公钥内容加到 HA 的 authorized_keys（插件配置里粘贴，或放到 /root/.ssh/）
```

### 2. 修改并运行部署脚本

编辑 `tools/deploy.py` 顶部三个变量：

```python
HOST = "192.168.1.10"                          # HA 地址
KEY  = r"C:\Users\你\.ssh\id_ed25519_ha"        # 私钥路径（没有就用 PASSWORD）
USER = "root"                                   # 官方 SSH 插件用户一般是 root
```

然后：

```bash
pip install paramiko
python tools/deploy.py
```

脚本会依次做四件事：

```
1. 把 custom_components/longyan_water 打包为 tar.gz
2. 通过 SSH stdin 传到远程 /tmp/
3. rm -rf 旧的 longyan_water 并解压到 /homeassistant/custom_components/
4. ha core restart
```

输出示例：

```
tar.gz: 1834217 bytes, 13 files
RECEIVED
EXTRACTED
__init__.py  api.py  captcha_templates.json  ...
Command completed successfully.
DONE
```

### 3. 验证是否装上

在 HA 里打开 **开发者工具 → 状态**，搜索 `zi_lai_shui`（实体 ID 会转成拼音），
能看到 8 个实体就说明集成加载成功。

或者 SSH 上查日志：

```bash
docker logs homeassistant 2>&1 | grep -i longyan_water | tail
```

正常应只有一条「We found a custom integration longyan_water which has not been tested by Home Assistant」的黄色警告，
**这条警告是正常的**，任何自定义集成都会有。

## 方式三：直接从 GitHub 下载（发布 Release 后）

如果本仓库打了 Release：

```bash
cd /config/custom_components
# 手动下载 zip 解压，或用 git
git clone https://github.com/<你的用户名>/longyan-water-ha.git /tmp/lw
cp -r /tmp/lw/custom_components/longyan_water /config/custom_components/
```

> ⚠️ HAOS 的 HA 容器内**不能直接访问 GitHub**（无外网或 DNS 受限），
> 所以 HAOS 用户还是推荐方式二（本机下载后 SSH 上传）。

## 卸载

1. 设置 → 设备与服务 → 找到「龙岩自来水 xxx」→ 删除
2. 删除 `/config/custom_components/longyan_water/` 目录
3. 重启 HA
