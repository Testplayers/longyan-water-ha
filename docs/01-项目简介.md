# 01 · 项目简介

## 背景

龙岩水发自来水（原龙岩市自来水公司）的网上营业厅是 `https://service.fjlyzls.com`，
底层是杭州水务的 `iwater` 平台。网厅只提供网页查询，没有开放 API，也没有 Home Assistant 集成。

本项目通过分析网厅前端 JavaScript，还原出查询接口，做成了 HA 自定义集成，
让水费数据自动同步到智能家居里，可以：

- 在仪表板上直接看到余额、本期用水量
- 余额不足时自动提醒
- 把用水量接进 HA 能源仪表板，看用量趋势

## 能拿到什么数据

每次刷新从网厅「查询户号列表」接口拿到该账号下**所有户号**的数据，每个户号生成 8 个传感器：

| 数据 | 来源字段 | 说明 |
|---|---|---|
| 账户余额 | `balance` | 元 |
| 欠费金额 | `arrearage` | 元，一般为 0 |
| 本期用水量 | `payMentList[0].consumedVolume` | m³，最近一个账单周期 |
| 本期读数 | `currentRead` | m³，本期抄表读数 |
| 上期读数 | `lastRead` | m³，上期抄表读数 |
| 水价单价 | `unitprice` | 元/m³ |
| 本期应缴 | `payMentList[0].payablePrincipal` | 元 |
| 上次抄表日期 | `lastreaddate` | 日期 |

> 注：账单按月出，抄表日通常是每月 1 号。**本期读数在账单出来前是 0**，属正常现象，
> 本期用水量以上期账单为准（见 [04 · 使用说明](04-使用说明.md)）。

## 工作原理

```
┌──────────────┐   requestPara=JSON    ┌─────────────────────┐
│ HA 集成       │ ────────────────────► │ service.fjlyzls.com │
│ longyan_water │                       │  (iwater 平台)       │
│              │ ◄──────────────────── │                     │
└──────┬───────┘   JSON 响应            └─────────────────────┘
       │
       │ 1. 每 6 小时（UpdateCoordinator）
       │ 2. 无 token 时：抓验证码图片 → 本地 OCR 识别 → 登录拿 token
       │ 3. 带 token 查户号列表
       │ 4. token 失效（status=11）→ 自动重新登录
       ▼
  8 个 sensor 实体
```

关键设计：

1. **验证码自动识别**：网厅登录要图形验证码，集成内置颜色聚类 + 模板匹配识别器，
   单字符准确率约 70%，靠 `login_auto()` 最多重试 12 次把整体成功率拉到接近 100%。
2. **token 自愈**：`coordinator.py` 捕获查询时的 `AuthError`，自动清掉 token 重新登录，
   所以长期运行不需要人工介入。
3. **人工兜底**：首次配置如果 OCR 连续失败，配置界面会把验证码图片直接显示出来，
   让用户手动输入一次。

## 代码结构

| 文件 | 职责 |
|---|---|
| `const.py` | 域名、接口路径、固定参数、验证码模板加载 |
| `api.py` | HTTP 客户端：`get_captcha` / `login` / `login_auto` / `meter_list` |
| `ocr.py` | 验证码识别：颜色聚类分割字符 → 归一化位图 → 与模板比对 |
| `coordinator.py` | `DataUpdateCoordinator`，6 小时刷新 + token 失效重登 |
| `config_flow.py` | 配置流程（自动登录 / 验证码人工输入两个步骤） |
| `sensor.py` | 8 个 `SensorEntity` 定义 |
| `entity.py` | 实体基类、设备信息（按户号 `bsh` 聚合为一个设备） |
| `captcha_templates.json` | 36 个字符 × 63 个变体的位图模板 |
