# 05 · 常见问题

## 集成相关

### Q: HA 里搜不到「龙岩水发自来水」

1. 确认 `custom_components/longyan_water/` 目录结构正确（直接放进去，不要多一层文件夹）
2. 确认 `manifest.json` 存在
3. **必须完全重启 HA**（不是重载），自定义集成首次加载需要重启
4. 重启后看日志有没有报错：

```bash
docker logs homeassistant 2>&1 | grep -i longyan_water
```

如果日志里完全没有 `longyan_water` 字样，说明文件路径不对。

### Q: 提示「自定义集成未经测试」警告

`We found a custom integration longyan_water which has not been tested by Home Assistant.`

**这是正常的**，所有自定义集成都有这条警告，不影响使用。

### Q: 添加集成时报「无法连接」

- 先确认网厅网页能正常打开、能登录（<https://service.fjlyzls.com>）
- 检查 HA 主机能不能上外网：SSH 里执行 `curl -I https://service.fjlyzls.com`
- 如果网厅本身挂了，集成也会连不上，等网厅恢复即可

### Q: 提示「用户名或密码错误」

- 确认用的是**网厅注册的手机号**，不是户号
- 密码区分大小写
- 到网厅网页登录一次，确认账号没被锁定

## 验证码相关

### Q: 一直卡在验证码输入界面

说明自动识别 12 次都错了。可能原因：

1. **验证码样式变了**（网厅改版）→ 重新生成模板，见 [06 · 更新与维护](06-更新与维护.md)
2. 临时性的识别质量波动 → 直接在界面上**人工输入**验证码即可完成配置；
   之后每 6 小时的刷新是复用 token 的，token 失效时才会再自动登录一次，
   失败会重试，一般不需要再人工介入。

### Q: 配置时看不到验证码图片

验证码图片是以 base64 内联在表单里的，少数浏览器/主题可能显示不出来。
可以改用「重新提交一次」触发新验证码；或直接在 HA 自带界面（非第三方主题）里操作。

## 数据相关

### Q: 余额/用水量长时间不变

水费是**按月出账**的（每月 1 号抄表），没到出账日数据自然不会变，
这和电费/燃气费的实时性是两回事，属正常现象。

### Q: 本期读数是 0

账单未生成时 `currentRead` 为 0，是网厅返回的原始值，不是集成出错。
用水量请看「本期用水量」实体。

### Q: 实体变成「不可用 / unavailable」

说明刷新时请求失败了。可能原因：

- 网厅临时故障或网络抖动 → 下个周期（6 小时后）会自动恢复
- 账号被限制 / 密码被改 → 需要重新配置集成
- 网厅改版 → 见 [06 · 更新与维护](06-更新与维护.md)

排查命令（在 HA 主机上）：

```bash
docker logs --since 1h homeassistant 2>&1 | grep -i longyan_water | tail -20
```

## 兼容性相关

### Q: HA 启动后配置条目丢失 / 启动崩溃

新版 HA（2026.x）要求配置条目 storage 里有 `subentries` 字段。
如果是**手动**往 `.storage/core.config_entries` 写条目，务必带上：

```json
{ "entry_id": "...", "domain": "longyan_water", "subentries": [], ... }
```

正常通过 UI 添加的不会有这个问题。

### Q: 报 `ImportError: cannot import name 'CURRENCY_YUAN'`

新版 HA 移除了 `homeassistant.const.CURRENCY_YUAN`。
本项目已改用字符串字面量 `"CNY"`，如果你改代码时用回了旧常量，就会报这个错。

### Q: 报 `ModuleNotFoundError: No module named 'PIL'`

Pillow 没装。`manifest.json` 里已声明 `requirements: ["pillow>=10.0.0"]`，
正常情况下 HA 会自动安装。如果你是手动复制文件，重启 HA 让它重新安装依赖，
或在 SSH 里手动装：

```bash
docker exec homeassistant pip install pillow
```

### Q: 想换水司 / 换城市能用吗

只要对方也是杭州水务 `iwater` 平台（登录接口同为 `/iwater/nt/wt/login.json`），
改 `const.py` 里的 `BASE_URL` 和 `waterCorpId` 基本就能用；
如果页面结构不同，需要按 [02 · 接口原理](02-接口原理.md) 重新抓包。
